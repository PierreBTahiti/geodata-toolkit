# geodata-toolkit
Outils automatisé traitement de données gesopatiales, environnement, risques naturels, ...

## Mesure et profil altimétrique

Sur la page de recherche d’adresse, le bouton situé sous la carte principale
permet d’afficher l’outil de mesure : trace une polyligne pour en mesurer la
longueur et voir son profil altimétrique. Les altitudes indicatives proviennent
du modèle RGE ALTI de l’IGN et nécessitent une connexion Internet. Le nombre
minimal de points du profil est réglable (10 à 100) ; les tracés longs sont
automatiquement échantillonnés plus densément, dans la limite de 100 points.
